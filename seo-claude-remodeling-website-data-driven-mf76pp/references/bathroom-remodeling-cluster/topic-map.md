## Consolidation notes

Four merges collapse the raw 28-slot AlsoAsked map into 16 real articles:

1. **"Hottest bathroom trends for 2026" / "new bathroom trends for 2026" / "new
   bathroom trend in 2026"** → one article, `bathroom-trends-2026`. Same search
   intent, three phrasings.
2. **"In-colour for bathrooms in 2026" / "most popular color for bathrooms right
   now"** → one article, `bathroom-color-trends-2026`, covering both the current
   popular color and the 2026 forward-looking angle.
3. **"How much should it cost to remove a tub and put in a shower?" / "How much to
   remove a bath and install a walk-in shower?"** → one article,
   `tub-to-shower-conversion-cost`.
4. **"What not to do in a bathroom remodel?"** → folded into the `what-to-avoid-bathroom-remodel`
   hub itself rather than spun into a separate near-duplicate article.

Every hub also cross-links to the other 3 hubs where genuinely relevant (budget
tiers naturally reference each other) — see `internal-link-map.md`.
